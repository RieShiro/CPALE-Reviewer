# CPALE Review v2

Updated based on testing:
- Separates numbered questions from PDF/pasted text.
- Removes common repeated page/header text.
- Detects A-D choices.
- Detects common answer-key formats (Answer: B, 567. C, etc.).
- Supports assigning an import to a Topic (e.g. Obligations, Contracts).
- Question Bank keeps subject/topic filters.
- Quiz supports subject + topic or all-topic shuffle.
- Progress page shows overall and topic mastery.
- Duplicate imports are skipped using normalized question+choices signatures.
- Mobile-first responsive layout.

For scanned PDFs, browser PDF text extraction cannot read images; OCR needs to be added for those files.
